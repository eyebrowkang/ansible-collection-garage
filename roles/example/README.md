# eyebrowkang.garage.example

Starter role for the `eyebrowkang.garage` collection. Replace the
placeholder task in `tasks/main.yml` with real content, and the assertion in the
molecule scenario's `verify.yml` (under `extensions/molecule/`) with real checks.

Tested by the collection-level molecule scenario (`make test` from the collection
root); molecule resolves this role by its short name via `ANSIBLE_ROLES_PATH`.
